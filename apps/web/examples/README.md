# Exemplos isolados

Esta pasta guarda experimentos de desenvolvimento, fora das rotas e do build
do aplicativo. Não é conteúdo publicado em `public/`.

- [test-tailwind.html](test-tailwind.html): verificação visual histórica que
  carrega o CDN do Tailwind. Não comprova a configuração do build Next.js atual
  e não é um teste automatizado da aplicação.

Para testar as interfaces atuais, use as prévias listadas no
[README do aplicativo](../README.md).
